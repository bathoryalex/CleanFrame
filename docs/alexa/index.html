Connect Alexa to Frame Home

Your password goes only to Amazon. The TV receives a one-time code that works only together with a secret kept on the TV.

1Sign in to Amazon

Use the Amazon account your Alexa app uses. Pick the Amazon site you signed up on.

amazon.de amazon.com

After signing in, Amazon shows an empty or “page not found” page. That is expected.

2Paste the address of that page

Copy the whole address from the browser’s address bar on the empty page and paste it here.

Open this page by scanning the QR code on the TV.
